Both features involve several dates, but they solve different problems. Mixing them up is one of the most common reasons for support questions.

## At a glance

| | Recurring invoice | Payment plan |
| --- | --- | --- |
| Purpose | Bill for new work again and again | Let a client pay one existing invoice in parts |
| What is created | A new invoice on every run | Nothing new; installments on one invoice |
| Total owed | Grows with each run | Fixed at the invoice balance |
| Client agreement | Not required | Client must accept the plan |
| Reminders | Normal reminders on each invoice | Normal reminders pause; installment reminders replace them |
| Late fees | Apply to each invoice | Paused while the plan is active |
| Plan limit | 3 / 50 / unlimited schedules | None |
| Typical use | Retainer, rent, membership | Overdue or large invoice |

## Choose a recurring invoice when

- You deliver a service every period and invoice for it each time.
- You want invoice numbers, due dates and tax to be created automatically.

Start from [Recurring invoices](/help/recurring/recurring).

## Choose a payment plan when

- A single invoice is large, and the client needs time to pay.
- An invoice is already overdue and you have agreed on a schedule.

Start from [Payment plans](/help/payments/payment-plans).

## Can I use both

Yes, but on different invoices. A payment plan attaches to a single invoice, including one generated by a schedule. For example, if a client falls behind on the January invoice of a monthly retainer, you can offer a plan for January while the schedule keeps issuing February, March and onward.

## A common mix-up: "installments"

If you want to bill a $3,000 project in three equal parts from the start, create three invoices (or a recurring schedule with 3 occurrences). Do not create one invoice and a plan, because the client would have to accept a plan on an invoice that was never overdue. Reminders for the first invoice would not behave as expected.

## Effect on late fees

A payment plan pauses late fees; a recurring schedule does not. See [Late fees](/help/billing/late-fees) and [Late fees on recurring invoices](/help/recurring/late-fees-on-recurring-invoices).
